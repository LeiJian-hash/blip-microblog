# Blip · 本地微动态

一个用**纯 HTML + CSS + JavaScript** 实现的极简微动态应用，数据全部保存在浏览器的 **Local Storage** 中，无需后端、无需构建、零第三方依赖。

> 项目为通用演示用途自行设计，不使用任何第三方平台的名称与标识。

## 功能

- **发布**：输入文字（上限 280 字，实时字数统计，超长时禁止发布），支持自定义昵称（本地记忆），可用 `Ctrl / Cmd + Enter` 快捷发布
- **查看**：按时间倒序展示，显示相对时间（刚刚 / N 分钟前 / N 小时前 / 日期），并显示动态总数
- **删除**：删除单条动态（二次确认），或一键清空全部数据
- **本地持久化**：刷新或关闭浏览器后数据仍在
- **安全**：所有用户内容通过 `textContent` 渲染，不会把 HTML 当标签执行
- **响应式**：桌面与移动端自适应

## 运行方式

方式一：直接双击 `index.html` 用浏览器打开。

方式二（推荐，避免个别浏览器对 `file://` 的限制）：在项目目录启动任意静态服务器。

```bash
# Python 3
python -m http.server 5173

# 或 Node.js
npx serve .
```

然后访问 <http://127.0.0.1:5173/index.html>。

## 目录结构

```
.
├── index.html   # 页面结构（发布框 / 时间线 / 动态模板）
├── styles.css   # 样式与响应式布局
└── app.js       # 数据读写与交互逻辑
```

## 存储设计

| 键名 | 类型 | 说明 |
| --- | --- | --- |
| `blip.posts.v1` | `Array<Post>` | 动态列表，最新的排在最前 |
| `blip.author.v1` | `string` | 上次使用的昵称 |

```ts
type Post = {
  id: string;         // crypto.randomUUID() 生成
  author: string;     // 昵称，留空时为「匿名用户」
  content: string;    // 正文，≤ 280 字
  createdAt: number;  // 毫秒时间戳
};
```

读取时会过滤掉结构异常的记录；若浏览器禁用存储，页面会给出提示而不是崩溃。

## 实现要点

- `app.js` 使用 IIFE 包裹，避免污染全局作用域
- 列表渲染使用 `<template>` + 事件委托，删除按钮无需逐个绑定
- 时间显示做相对格式化，鼠标悬停可查看完整时间
- 空状态、错误提示、字数告警（剩余 40 字变黄、超出变红）均有对应反馈
